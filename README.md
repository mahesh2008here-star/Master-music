# MasterWave Music 🎵

MasterWave is a production-grade, feature-rich music streaming application designed for audiophiles and music lovers. It combines the seamless recommendation algorithms of YouTube Music and Spotify with an exquisite Apple Music and Material You inspired interface, featuring Hi-Res lossless telemetry, live LRCLIB synchronized golden glowing lyrics, offline downloads with local device export, and real-time social listening jams.

---

## ✨ Key Features

### 🎧 Immersive Playback & Now Playing Experience
- **Precision Mirrored Acoustic Waveform**: Hi-DPI micro-filament visualizer with glowing gradient progress and touch-seeking.
- **Atmospheric Visual Motion**: Fluid rotating cover art canvas and atmospheric blur background motion.
- **Hi-Res Telemetry**: Detailed audio codec inspection (AAC 320 kbps, FLAC lossless, sample rate, bit depth, and hardware HAL audio path).

### 🤖 Intelligent Recommendation Engine
- **Co-Listening Algorithms**: YouTube Music and Spotify inspired home feed curation with automatic top picks and quick picks.
- **Mood & Taste Discovery**: Instant genre and vibe radio generation (Pop, Rock, Hip Hop, Indie, Romance, Relax).
- **Artist & Album Hubs**: Detailed artist pages with verified seals, biographies, popular tracks, and albums.

### 🔍 Multi-Service Search & Discovery
- **Unified Search**: Search across multiple music streaming providers simultaneously.
- **Dedicated Categories**: Filter search results instantly by Songs, Albums, Artists, Podcasts, and Playlists.
- **Podcast & Show Streaming**: Browse and stream episodic audio content directly.

### 💾 Offline Downloads & Storage
- **Offline-First Caching**: Download songs with embedded album artwork and metadata for playback without internet access.
- **Device Export**: Save merged audio + cover art files directly to local storage (`.m3u` bundles and audio exports).

### 🎨 Material 3 & Glassmorphism UI
- **Liquid Glass Dock**: iOS and Android Material You translucent material design.
- **Custom Animated Icons**: Polished micro-interactions and animated equalizers.
- **Echo Music Settings**: Beautiful rounded card groups and pastel icon tiles for appearance, audio, library, and system preferences.

---

## 🚀 Tech Stack

- **Frontend**: React 19, Vite, Tailwind CSS 4, Lucide Icons, Canvas API.
- **Backend**: Node.js, Express, TypeScript (`tsx`).
- **Data & Extraction**: YouTubei.js, JioSaavn API, LRCLIB synchronized lyrics API, Wikipedia REST API.

## 🛠️ Getting Started Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/masterwave-music.git
   cd masterwave-music
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   npm start
   ```
